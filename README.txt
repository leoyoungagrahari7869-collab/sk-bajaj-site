Preview:
Extract the ZIP and open index.html in a modern browser. Internet is required for the illustrative remote motorcycle image.

Publish free using GitHub Pages:
1. Create a GitHub account and a public repository named sk-bajaj.
2. Upload index.html, style.css and script.js to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will show the public website address after deployment.
